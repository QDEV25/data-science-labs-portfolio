# data-science-labs-portfolio
Complete data science lab collection: Sales analysis, customer segmentation (K-Means/PCA), and Google Trends prediction. Built with pandas, scikit-learn, and matplotlib.

# Data Science Labs Portfolio

A comprehensive collection of data analysis and machine learning labs demonstrating practical skills in:

##  Labs Included

### Lab 02 - Sales Data Analysis
- Exploratory Data Analysis (EDA) on sales transactions
- Statistical analysis and visualization
- Product performance metrics

### Lab 03 - Advanced Sales Analytics  
- Time series analysis (year/month trends)
- Linear regression (manual + scikit-learn)
- Correlation analysis between Unit Cost and Unit Price

### Lab 04 - Customer Segmentation (Machine Learning)
- Feature engineering (Age, Family Size, Total Spending)
- Outlier detection and removal (IQR method)
- PCA dimensionality reduction
- K-Means clustering for customer profiling
- 3D cluster visualization
- Marketing recommendations per segment

### Lab 05 - Google Trends Prediction
- Real-time data collection via pytrends API
- Time series feature engineering (rolling averages, lag features)
- Binary classification (growth prediction)
- Logistic Regression vs Decision Tree comparison
- Feature importance analysis

##  Technologies Used
- Python 3.8+
- pandas, numpy (data manipulation)
- matplotlib, seaborn (visualization)
- scikit-learn (PCA, K-Means, Logistic Regression, Decision Tree)
- pytrends (Google Trends API)

##  Key Skills Demonstrated
- Data cleaning & preprocessing
- Feature engineering
- Statistical analysis
- Machine learning modeling
- Cluster interpretation
- Time series prediction

## Business Applications
- Customer segmentation for targeted marketing
- Sales trend forecasting
- Google Trends-based content strategy
- Budget allocation optimization

##  How to Run
1. Clone repository
2. Install requirements: `pip install -r requirements.txt`
3. Run Jupyter notebooks in order (Lab_02.ipynb → Lab_05.ipynb)

##  Results
- Lab 04: Successfully identified 3 customer clusters with distinct spending patterns
- Lab 05: Achieved ~60-65% accuracy in predicting search interest growth
